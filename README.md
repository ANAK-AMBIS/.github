# ANAK-AMBIS/.github

Repo khusus untuk **Organization Profile** dari [Anak Ambis Project](https://github.com/ANAK-AMBIS).

GitHub akan menampilkan isi dari [`profile/README.md`](./profile/README.md) di halaman overview organisasi: https://github.com/ANAK-AMBIS

## Struktur

```
.
├── profile/
│   └── README.md   # <- profile README yang tampil di org
└── README.md       # file ini (pointer)
```

## Cara Edit Profile

Edit `profile/README.md`, lalu push ke branch `main`:

```bash
git add profile/README.md
git commit -m "docs: update organization profile"
git push origin main
```

Perubahan akan muncul di https://github.com/ANAK-AMBIS dalam 1-2 menit.
