# Support — Anak Ambis Project

Butuh bantuan? Ini jalur yang disarankan:

## 📌 Untuk Repo Spesifik (mis: LampungWifi)
- **Bug / Error** → Buka Issue di `ANAK-AMBIS/<nama-repo>` dengan label `bug`
- **Fitur / Ide** → Issue label `enhancement`
- **Pertanyaan umum** → Discussions (jika diaktifkan) atau Issue label `question`

## 🏢 Untuk Organisasi Umum
- Buka Issue di [`ANAK-AMBIS/.github`](https://github.com/ANAK-AMBIS/.github/issues)
- Atau hubungi maintainer via kontak yang tertera di [`profile/README.md`](./profile/README.md)

## ⏱️ Respon
Kami usahakan respon dalam **1–3 hari kerja**. Untuk issue urgent, tambahkan label `priority: high`.

## 🔒 Laporan Sensitif / Code of Conduct
Jika terkait pelanggaran etik atau data sensitif, jangan buka issue publik — hubungi maintainer langsung (email tertera di profil org).
